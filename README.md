# FaceIt Stats - Приложение для отслеживания статистики CS:GO игроков

## Описание

FaceIt Stats - это веб-приложение для отслеживания статистики игроков CS:GO на платформе FaceIt. Приложение предоставляет детальную информацию об игроках, их матчах, статистике и позволяет пользователям создавать заметки, отслеживать цели и анализировать прогресс.

## Ограничения FACEIT API

Приложение использует официальное FACEIT API, которое имеет некоторые ограничения:

- **Новые матчи**: Отображается реальный счет по раундам (13-3, 16-14)
- **Старые матчи**: Отображается только результат матча (1-0 = победа, 0-1 = поражение)

## Основные возможности

### Поиск игроков
- Поиск по никнейму
- Отображение основной статистики (K/D, Win Rate, количество матчей)
- Детальная информация об игроке

### Цели и достижения
- Создание персональных целей по различным метрикам
- Автоматическое отслеживание прогресса
- Визуализация достижений

### Личные заметки
- Создание заметок о матчах и тиммейтах
- Поиск и фильтрация заметок
- Привязка к конкретным игрокам или матчам
